ในภาษา Rust ตัวแปรจะเป็นแบบ **ไม่สามารถเปลี่ยนแปลง (Immutable)** โดยค่าเริ่มต้น
นี่คือวิธีการที่ Rust ช่วยให้เราเขียนโค้ดได้ปลอดภัยขึ้น

## เดี๋ยวเราจะลองเขียนโค้ดที่คอมไพล์ไม่ผ่านดูว่าเพราะอะไร?

ถ้าเราพยายามเปลี่ยนค่าตัวแปรแบบดื้อๆ เลย คอมไพเลอร์จะด่าเราทันที

```rust
fn main() {
    let x = 5;
    println!("ค่าของ x คือ: {x}");
    x = 6;  // ❌ Error! assign twice to immutable variable
    println!("ค่าของ x คือ: {x}");
}
```

> **ทำไมถึงออกแบบมาแบบนี้?** การทำให้ตัวแปรไม่เปลี่ยนแปลงโดยค่าเริ่มต้น
> ช่วยลดข้อผิดพลาดจากการเปลี่ยนค่าโดยไม่ตั้งใจ ซึ่งเป็นปัญหาที่พบบ่อยมาก
> ในการเขียนโปรแกรม (Concurrency Bug)

## แล้วเราจะทำให้ตัวแปรเปลี่ยนแปลงได้อย่างไร?

ถ้าอยากเปลี่ยนค่าจริงๆ ต้องใช้คีย์เวิร์ด `mut` นำหน้าครับ
ซึ่ง `mut` ย่อมาจาก **mutable** นั่นเอง

```rust
fn main() {
    let mut x = 5; // ✅ ใส่ mut แล้ว
    println!("ค่าของ x คือ: {x}");
    x = 6;
    println!("ค่าของ x คือ: {x}");
}
```

เมื่อคอมไพล์เราจะได้ `ค่าของ x คือ: 6` (จะเห็นว่าค่าของ x เปลี่ยนไปแล้ว)

## สิ่งที่น่าสนใจ

บทความนี้ไม่ได้เป็นแค่เรื่องราวเกี่ยวกับ Rust แต่มัน **ถูกสร้างขึ้นด้วย Rust**
และกำลังทำงานอยู่บนเบราว์เซอร์ของคุณผ่าน WebAssembly โดยใช้เฟรมเวิร์ก Leptos

ลองนึกภาพว่า Counter ด้านล่างนี้คือ Rust Signal ที่มีสถานะ (state)
ทำงานจริงบนเครื่องคุณ — ไม่ใช่ JavaScript!

```rust
use leptos::prelude::*;

#[component]
fn Counter() -> impl IntoView {
    let (count, set_count) = create_signal(0);
    view! {
        <button on:click=move |_| set_count.update(|n| *n += 1)>
            {move || count.get()}
        </button>
    }
}
```

อบเครื่องร้อนๆ ที่ได้เรียนรู้กันไปแล้ว see you ในบทความหน้า! 🦀
