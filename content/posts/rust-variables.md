โดยค่าเริ่มต้น (Default) แล้ว ตัวแปรทุกตัวในภาษา Rust จะเป็นแบบ **แก้ไขค่าไม่ได้ (Immutable)** ซึ่งนี่คือหนึ่งในกลไกสำคัญที่ทำให้โค้ดของเราปลอดภัยและลดข้อผิดพลาดตั้งแต่ตอนคอมไพล์

## ลองเขียนโค้ดให้คอมไพล์ไม่ผ่านดูว่าเกิดอะไรขึ้น

ถ้าเราพยายามไปเปลี่ยนค่าของตัวแปรที่ถูกประกาศไว้เฉย ๆ คอมไพเลอร์จะฟ้อง Error ขึ้นมาทันที

```rust
fn main() {
    let x = 5;
    println!("ค่าของ x คือ: {x}");
    x = 6;  // ❌ Error! cannot assign twice to immutable variable
    println!("ค่าของ x คือ: {x}");
}
```

> 💡 **ทำไมถึงออกแบบมาแบบนี้?**  
> การกำหนดให้ตัวแปรแก้ไขค่าไม่ได้ตั้งแต่แรก ช่วยป้องกันปัญหาการเผลอเปลี่ยนค่าโดยไม่ได้ตั้งใจ ซึ่งมักเป็นสาเหตุหลักของบั๊กกวนใจ โดยเฉพาะเวลาทำงานร่วมกับระบบ Multithreading หรือ Concurrency

## แล้วถ้าอยากให้ตัวแปรเปลี่ยนค่าได้ ต้องทำอย่างไร?

หากต้องการให้ตัวแปรนั้นสามารถแก้ไขค่าได้จริง ๆ เราต้องระบุคีย์เวิร์ด `mut` (ย่อมาจาก **mutable**) ไว้ข้างหน้าชื่อตัวแปร

```rust
fn main() {
    let mut x = 5; // ✅ ใส่ mut เพื่อเปิดให้แก้ไขค่าได้
    println!("ค่าของ x คือ: {x}");
    x = 6;
    println!("ค่าของ x คือ: {x}");
}
```

เมื่อนำไปรัน โค้ดจะทำงานได้ตามปกติ และแสดงผลลัพธ์ว่า `ค่าของ x คือ: 6`

## ความพิเศษของหน้านี้

บทความที่คุณกำลังอ่านอยู่นี้ไม่ได้แค่เล่าเรื่องภาษา Rust เท่านั้น แต่มัน **ถูกสร้างและรันด้วย Rust จริง ๆ** บนเบราว์เซอร์ของคุณผ่านเทคโนโลยี WebAssembly โดยใช้เฟรมเวิร์ก Leptos

อย่างโค้ดปุ่มนับเลข (Counter) ด้านล่างนี้ ก็ถูกจัดการ State ด้วย Rust Signal และทำงานบนเครื่องของคุณโดยตรง โดยไม่ต้องพึ่งพา JavaScript เลย

ลองกดปุ่มที่รันด้วย Rust จริง ๆ ด้านล่างนี้ได้เลย:

```demo
counter
```

และนี่คือซอร์สโค้ดที่รันอยู่เบื้องหลังปุ่มนั้น

```rust
use leptos::prelude::*;

#[component]
fn Counter() -> impl IntoView {
    let (count, set_count) = create_signal(0);
    view! {
        <button on:click=move |_| set_count.update(|n| *n += 1)>
            {move || count.get()}
        </button>
    }
}
```

หวังว่าบทความนี้จะช่วยให้เห็นภาพเรื่อง Immutability ใน Rust ชัดเจนยิ่งขึ้น
