สวัสดีครับ นี่คือบทความแรกบน **rust-blog** รุ่นใหม่ที่เพิ่งรื้อและวางรากฐานใหม่ทั้งหมด - ไม่ใช่บล็อกที่เขียนเกี่ยวกับ Rust เท่านั้น แต่เป็นบล็อกที่ "ถูกเขียนด้วย" Rust ด้วย

## รันด้วย Rust จริงๆ

จุดที่ทำให้บล็อกนี้ต่างจากบล็อกทั่วๆ ไปคือ ฝั่งผู้ใช้ไม่ได้ใช้ JavaScript แม้แต่บรรทัดเดียว ทุกอย่างวางรากฐานบน:

- **Rust** (Edition 2024)
- **Leptos 0.8** ในโหมด Client-Side Rendering (CSR)
- **Trunk** เป็นตัวจัดการ build
- และถูกคอมไพล์เป็น **WebAssembly** เพื่อทำงานบนเบราว์เซอร์โดยตรง

ไฮไลต์โค้ดในบทความก็เกิดจาก `syntect` ณ เวลา render เช่นกัน - ไม่มี CDN, ไม่มี JavaScript ในกองไฟล์ของเว็บนี้

## เพิ่มบทความใหม่ได้ง่ายๆ

โครงสร้างถูกออกแบบมาให้รองรับการเติมบทความในอนาคต โดยใช้ไฟล์ Markdown ธรรมดา:

```bash
# สร้างไฟล์ใหม่ในโฟลเดอร์ content/posts/
echo '---\ntitle: "บทความใหม่"\ndate: "2024-07-01"\ntags: [rust]\n---\n\nเนื้อหาบทความ...' > content/posts/my-post.md
```

เพียงแค่นั้น บล็อกจะแสดงบทความใหม่ให้โดยอัตโนมัติ - ไม่ต้องแก้โค้ด ไม่ต้อง deploy ทีละไฟล์

## ฟีเจอร์ที่มีให้

- โหมดกลางวัน / กลางคืน (Dark mode) พร้อมจดจำค่าที่เลือกไว้
- ค้นหาและกรองบทความด้วยแท็ก
- โค้ดที่ไฮไลต์ด้วย syntect - เรียบแต่คม
- Feed แบบ RSS (`/rss.xml`) สร้างขึ้นตอน build
- ดีไซน์ที่ตอบสนองทุกขนาดหน้าจอ แบบ editorial ที่เรียบง่าย

บล็อกนี้เกิดจากคำถามง่ายๆ ข้อหนึ่ง: เว็บส่วนตัวของคนที่เขียน Rust จะดูเป็นอย่างไร ถ้าเขาเขียนมันขึ้นมาด้วย Rust ทั้งหมด? และนี่คือคำตอบของเราครับ

แล้วพบกันใหม่ในบทความถัดไป
