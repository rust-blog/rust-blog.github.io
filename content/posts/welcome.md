สวัสดีครับ! นี่คือบทความแรกบน **rust-blog** รุ่นใหม่ที่เพิ่งรื้อและวางรากฐานใหม่ทั้งหมด 🎉

## รันด้วย Rust จริงๆ

เว็บไซต์นี้ไม่ได้ใช้ JavaScript สำหรับฝั่งผู้ใช้เลย แต่วางรากฐานด้วย:

- **Rust** (Edition 2024)
- **Leptos 0.8** ในโหมด Client-Side Rendering (CSR)
- **Trunk** เป็นตัวจัดการ build
- และถูกคอมไพล์เป็น **WebAssembly** เพื่อทำงานบนเบราว์เซอร์โดยตรง

## เพิ่มบทความใหม่ได้ง่ายๆ

โครงสร้างถูกออกแบบมาให้รองรับการเติมบทความในอนาคต โดยใช้ไฟล์ Markdown ธรรมดา:

```bash
# สร้างไฟล์ใหม่ในโฟลเดอร์ content/posts/
echo '---\ntitle: "บทความใหม่"\ndate: "2024-07-01"\ntags: [rust]\n---\n\nเนื้อหาบทความ...' > content/posts/my-post.md
```

เพียงแค่นั้น บล็อกจะแสดงบทความใหม่ให้โดยอัตโนมัติ — ไม่ต้องแก้โค้ดเลย

## ฟีเจอร์ที่มีให้

- 🌗 โหมดกลางวัน / กลางคืน (Dark mode)
- 🔍 ค้นหาและกรองบทความด้วยแท็ก
- 📜 โค้ดที่ไฮไลต์ด้วย highlight.js
- 📰 Feed แบบ RSS (`/rss.xml`)
- 📱 ดีไซน์ที่ตอบสนองทุกขนาดหน้าจอ

ขอเชิญชวนให้กดติดตาม และไว้พบกันในบทความถัดไปครับ!
